01 · Overview

A virtual cobot workplace focused on system awareness.

The prototype recreates the core idea of a multimodal Human–Robot Interaction interface inside a simple XR environment. Instead of only watching the robot move, the user can understand what it is doing and what happens next.

01 ◫

Virtual workplace

A simplified 3D workspace containing a collaborative robot, worktable, colored objects and task areas.

02 ◉

Observable robot state

Robot activity is communicated continuously so the user can see whether the system is idle, working, waiting or experiencing an error.

03 ≋

Multimodal feedback

Color, movement, textual explanations and task progress reinforce one another to communicate the current system behavior.

02 · Interaction

From user preference to robot action.

03 · System States

Four states. One consistent language.

Each robot state combines a distinct color with a textual explanation and corresponding robot behavior.

01

Idle

The robot is stationary and ready to receive the next user-defined task.

Ready for a command
02

Working

The robot is actively executing part of the selected task.

Transporting green box
03

Waiting

The robot has paused because input or confirmation from the user is required.

Waiting for user action
04

Error

The task cannot continue normally and requires the user's attention.

Attention is required
Prototype Scope

Start simple. Make the system state understandable.

This prototype currently focuses on explicit robot states, user-defined tasks and multimodal system feedback. Adaptive interfaces and biosensing are intentionally outside the current scope.
